# TypeRequest

The type of VRN. Defaults to `business` if omitted. `consumer` is only available if enabled for your program.


## Example Usage

```java
import com.newline53.sdk.models.operations.TypeRequest;

TypeRequest value = TypeRequest.BUSINESS;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `BUSINESS` | business   |
| `CONSUMER` | consumer   |
